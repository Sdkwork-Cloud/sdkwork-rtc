# SDKWork RTC Flutter Mobile Application

Flutter mobile application for SDKWork RTC. Native iOS and Android experience for rooms, media sessions, and participant management.

## Architecture

- Root: `FLUTTER_APP_MOBILE_ARCHITECTURE_SPEC.md`
- SDK: `sdkwork-rtc-app-sdk` (generated Dart)
- Packages: `sdkwork_rtc_flutter_mobile_core`, `sdkwork_rtc_flutter_mobile_commons`, `sdkwork_rtc_flutter_mobile_shell`, `sdkwork_rtc_flutter_mobile_rtc`, `sdkwork_rtc_flutter_mobile_admin_core`

## Development

```powershell
flutter pub get
flutter run
```
