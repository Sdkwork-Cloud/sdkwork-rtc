# SDKWork RTC H5 Application

H5 mobile web application for SDKWork RTC. Phone-first touch interface for rooms, media sessions, and participant management.

## Architecture

- Root: `APP_H5_ARCHITECTURE_SPEC.md`
- SDK: `sdkwork-rtc-app-sdk` (generated)
- Packages: `sdkwork-rtc-h5-core`, `sdkwork-rtc-h5-commons`, `sdkwork-rtc-h5-shell`, `sdkwork-rtc-h5-rtc`

## Development

```powershell
pnpm install
pnpm run dev
```
